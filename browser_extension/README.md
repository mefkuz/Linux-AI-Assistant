# Linux AI Asistan - Tarayıcı Eklentisi

Bu eklenti, tarayıcınız (Chrome, Brave, Edge vb.) ile yerel Linux AI Asistanınız arasında köprü kurar.

## Kurulum (Chrome / Brave / Edge)
1. Tarayıcınızda adres çubuğuna `chrome://extensions/` yazın (Brave için `brave://extensions/`).
2. Sağ üst köşeden **Geliştirici modu**'nu (Developer mode) açın.
3. Sol üstteki **Paketlenmemiş öğe yükle** (Load unpacked) butonuna tıklayın.
4. Çıkan pencerede bu klasörü (`browser_extension`) seçip onaylayın.

## Nasıl Kullanılır?
* **Eklenti Butonu:** Tarayıcınızın sağ üstündeki eklenti ikonuna (yapboz) tıklayıp AI Asistan ikonuna bastıktan sonra "Bu Sekmeyi Gönder" derseniz, o anki sayfa saniyesinde asistana bağlam (context) olarak iletilir.
* **Sağ Tık Menüsü:** Sayfada herhangi bir metni seçip sağ tıkladığınızda **"Linux AI Asistan'a Sor"** seçeneğini göreceksiniz. Seçtiğiniz metin doğrudan asistana gönderilir!
